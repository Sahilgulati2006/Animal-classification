A **deep learning-based image classification model** that utilizes **Transfer Learning** to classify images of different animals with high accuracy. This project leverages **pre-trained CNN architectures** (such as VGG16, ResNet50, EfficientNet) to fine-tune on an animal dataset, significantly improving classification performance.

---

## 🚀 **Project Overview**
With **Transfer Learning**, we take advantage of powerful **pre-trained convolutional neural networks (CNNs)** trained on massive datasets like **ImageNet** and fine-tune them for **animal classification**. This method enhances accuracy while minimizing training time and resource usage.

✅ **Key Features:**
- **Pre-trained Models**: Uses VGG16, ResNet50, EfficientNet for Transfer Learning.
- **Optimized Training**: Data Augmentation, Batch Normalization, Dropout for improved generalization.
- **High Accuracy**: Achieves **90%+** accuracy on validation data.
- **Real-time Prediction**: Classifies new images with a simple command.
- **Performance Metrics**: Includes **Confusion Matrix, Accuracy, Precision, Recall, and F1-score**.
